Floor Tracker is a browser-based app for running a warehouse unloading shift from a phone.
Set up your doors at the start of a shift, add your crew, and move workers between trailers as the day goes. The board shows which doors are being worked, which are sitting empty, and how far along each trailer is. At the end of the shift it produces a summary and a PDF.
Features
Set up a shift by door number, trailer ID, and piece count
Place workers into doors and move them between doors with two taps
Track which doors are being worked and which are sitting empty
Time each trailer, with the clock pausing automatically when nobody is inside
Record completion checkpoints from 10% to 100% on a trailer
Show progress as a fill bar on each door
Keep a running log of every placement, move, checkpoint, and completion
Count open and finished doors on a live counter
Open a list of working or finished trailers and act on them from there
Mark a finished trailer unfinished to put it back on the board
Keep a note on any door
Reuse a door number once its previous trailer is finished
Review a shift summary of lumpers, finished trailers, and rollovers
Show the percentage remaining on rolled-over trailers
Total the completed container piece count
Save a shift summary as a PDF
Store finished shifts and reopen them later
Switch between dark and light themes
Who this is for
Floor Tracker is for warehouse leads and supervisors who assign lumpers to trailers during a shift and have to report on what got unloaded.
It is especially useful if the same information — door, trailer, crew, piece count, completions, rollovers — has to be written on several forms during the day, and you would rather have it all in one place while the shift is still running.
Requirements
A modern web browser
Internet access the first time you save a PDF in a session
No installation, account, or server is needed. Everything runs in the browser.
Setup
1. Open it
Go to https://bjessief-apps.github.io/Floor-Tracker/
2. Add it to your phone
With the page open on your phone, use your browser's Add to Home screen option. It will open like an app.
3. Start a shift
Enter a door number, trailer ID, and piece count, then press enter or tap + to add each door. Tap Start shift when the list is complete.
How it works
Doors. Each door shows its number, piece count, a note icon, and a menu. Doors with people in them are marked orange. Doors that have been started but are sitting empty turn grey and drop to the bottom. Finished trailers leave the board.
Workers. Add names in the crew box. Tap a name to select it, then tap a trailer to place them. Tap a placed name to select it, then tap another trailer to move them, or tap them again to pull them off.
Timing. A trailer's clock starts when the first person is placed and pauses when the last person is pulled off, so the recorded time is worked time rather than clock time.
Checkpoints. The trailer menu records how far along a trailer is. The percentage shows as a fill on the left edge of the card.
Finishing. Mark a trailer complete from its menu or from the Done list. Finished trailers are counted, timed, and kept for the summary.
Summary. The menu's Finish shift option opens a summary of lumpers, finished trailers, and rollovers, with the percentage remaining on anything unfinished. Save it as a PDF from the icon in the top right.
Storage
Shift data is stored in the browser on the device you are using. It is not uploaded anywhere and is not shared between devices or browsers.
Clearing your browser's site data will delete saved shifts. Save the PDF at the end of each shift if you need a permanent record.
